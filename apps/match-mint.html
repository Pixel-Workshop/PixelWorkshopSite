Match Mint

Match Mint is a crisp memory puzzle built for short, satisfying sessions with more ways to build a run. Stack combo multipliers, create special tiles from 4+ matches, break through blocker tiles, use hints when you need a nudge, earn daily streak rewards, and climb campaign and daily leaderboards through Game Center.

Features

Built for Bigger Runs

Combo Multipliers

Build bigger scores by chaining clean matches together and letting the combo multiplier keep climbing.

Special Tiles

Create powerful special tiles from 4+ matches and use them to swing difficult boards back in your favor.

Blocker Tiles

Break through new blocker tiles that add friction, force better board reading, and make late-round decisions matter more.

Hints and Tutorial

Use the new Hint button when you get stuck and learn faster with an improved tutorial flow.

Daily Streak Rewards

Complete challenges on consecutive days to build a streak and unlock better daily rewards.

Game Center Leaderboards

Connect to Game Center and compete on campaign and daily leaderboards without changing the fast, pick-up-and-play core loop.

Fast Memory Rounds

Play quick boards designed to test recall without overwhelming you, now with better balance and cleaner reward pacing.

Offline Core Play

Standard gameplay still works offline. Game Center features can sync when you are connected and signed in.
